# Nomix prototype

A clickable prototype of Nomix: connect a restaurant's tools one at a time, choose what to keep track of, and see every store's data land in one data dictionary.

- English: https://hellohi6228-code.github.io/nomix-prototype/
- 中文: https://hellohi6228-code.github.io/nomix-prototype/zh.html

The sign-ins and incoming orders are simulated with sample data for an example restaurant group. Choices are saved only in the viewer's own browser; "Set up again" at the bottom of the home screen starts over.

Vendor logos belong to their owners and are shown only to identify each integration.
