# Nomix prototype

A clickable prototype of Nomix for NOMIX Hospitality Group: connect each brand's tools one at a time, choose what to keep track of, and see every store's data land in one data dictionary.

- English: https://hellohi6228-code.github.io/nomix-prototype/
- 中文: https://hellohi6228-code.github.io/nomix-prototype/zh.html

Brands and store locations come from NOMIX's own site (Umiya, Surfing Crab, Hibachi Grill & Supreme Buffet). Sign-ins, orders and prices are simulated. Choices are saved only in the viewer's own browser; "Set up again" at the bottom of the home screen starts over.

Vendor logos belong to their owners and are shown only to identify each integration.
